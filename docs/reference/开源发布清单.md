# 开源发布清单

目标：使用者克隆独立仓库，在自己的 Windows 电脑启动 TestForge。当前结论：仓库拆分与脱敏已完成，发布仍有阻断项。详细过程见[公开准备记录](公开准备记录.md)。

| 项目 | 状态 | 当前结果 |
| --- | --- | --- |
| 独立 Git | PASS | 平台拥有自身 .git，main 分支；不继承私有聚合仓库历史 |
| 私有材料隔离 | PASS | 原任务档案、运行日志、截图和 OSS 示例移出公开目录；历史证据清单重置 |
| 源码凭据扫描 | PASS | Gitleaks v8.30.1 扫描公开源码快照，无密钥命中 |
| README / 配置入口 | PASS | 平台内维护启动、配置、贡献与安全说明 |
| 本地基础设施 | PASS | 干净副本使用新数据卷和独立端口启动 MySQL、Redis、MinIO，桶初始化成功 |
| 后端公共依赖 | BLOCKED | 两个 yhc.framework 依赖未发布到 Maven Central，需替换或授权发布源码 |
| 开源许可证 | BLOCKED | 等待仓库所有者选择 Apache-2.0 或 MIT |
| 完整干净启动 | BLOCKED | 后端公共依赖问题尚未解决 |
| 固定主流程 E2E | NOT_RUN | 发布候选必须使用当前源码重新执行，不能引用旧私有证据 |
| 完整依赖与第三方许可审计 | NOT_RUN | 已有部分扫描结果，不等于全部依赖通过 |
| 公网部署 | 不适用 | 当前支持范围为本机运行 |
| GitHub 发布 | NOT_RUN | 没有配置远端或上传仓库 |

截图、视频和二进制 Release 在制作或发布相应材料时验证，不作为克隆源码的前置条件。
