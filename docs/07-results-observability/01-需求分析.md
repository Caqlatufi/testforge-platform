# TestForge 结果、事件与可观测性需求分析

> 核心业务闭环：测试任务执行产生结果和状态事件后，平台把它们聚合为确定性报告、历史波动证据、资源指标和可续传时间线，使测试工程师能够解释“结果是什么、为什么、过程发生了什么”。

## 1. 目标

| 项 | 内容 |
| --- | --- |
| 目标用户/系统 | 分析测试结果的测试/开发工程师，以及观察队列、Provider、Agent、资源和故障恢复的平台管理员 |
| 触发场景 | 测试任务正在执行需要实时观察，或全部 Task 终态后需要分析报告与历史表现 |
| 当前问题 | 单个 Task 状态不能形成质量结论；当前运行中心把任务列表、执行图、资源、节点明细和报告叠在同一主视图，容易把不同测试任务的上下文混在一起；断线会丢失观察上下文；跨版本结果混比会误判 Flaky |
| 期望结果 | 用户获得与原始结果一致的聚合指标、失败分类、附件索引、历史序列和可恢复事件时间线 |
| 业务价值 | 测试失败和调度故障能够被量化、追溯和复盘，为人工排查和 AI 辅助诊断提供可信证据 |

## 2. 核心业务流程

| 步骤 | 执行者 | 动作 | 系统响应或状态变化 |
| --- | --- | --- | --- |
| 1 | Execution Provider/运行编排器 | 提交有效 TaskAttempt 结果或 BLOCKED 结果 | 保存与 Task 唯一关联的 TestResult 和附件索引 |
| 2 | 各业务模块 | 在状态变化时追加带时间、原因和关联 ID 的事件 | 形成按 aggregateId 可追溯的只追加事件序列 |
| 3 | 测试工程师 | 打开“运行与报告”主页面 | 先看到全局执行资源与队列，再按一行一个测试任务查看当前/最近一次运行概述 |
| 4 | 测试工程师 | 点击某行“查看报告” | 进入只属于该测试任务及所选执行的二级详情页，获取 REST 快照并通过 SSE 接收后续状态更新 |
| 5 | 报告能力 | 在全部 Task 终态后聚合结果 | 计算通过率、耗时分位、失败分类和附件集合 |
| 6 | 测试工程师 | 查询同 Case 的历史表现 | 按 Case、脚本版本和环境返回最近结果与 Flaky 证据 |
| 7 | 平台管理员 | 查看 Metrics、结构化日志和时间线 | 从请求、派发、执行到回调定位链路问题 |

## 3. 关键规则

| 编号 | 规则 | 生效条件 | 影响的流程步骤 |
| --- | --- | --- | --- |
| RO-R1 | 每个 taskId 只有一个有效 TestResult；BLOCKED 可无 attemptId，但必须记录 blockedBy | 结果写入 | 1 |
| RO-R2 | 只有全部 Task 终态后报告才视为完整；FIXTURE 不计入断言通过率分母 | 报告聚合 | 4 |
| RO-R3 | P50/P95 只统计具有有效执行耗时的结果 | 耗时聚合 | 4 |
| RO-R4 | PRODUCT_DEFECT、SCRIPT_ERROR、ENVIRONMENT、WORKER_LOST、FLAKY、BLOCKED、UNKNOWN 由确定性规则产生，AI 不得覆盖 | 失败分类 | 4 |
| RO-R5 | CaseHistory 只比较相同 caseId、scriptVersion 和 environment 的结果 | 历史查询 | 5 |
| RO-R6 | 最近窗口同时出现通过和失败才形成 Flaky 波动证据 | 历史聚合 | 5 |
| RO-R7 | ExecutionEvent 只追加，包含聚合对象、状态、原因、executionId/taskId/attemptId/deploymentId 和发生时间 | 状态变化 | 2 |
| RO-R8 | SSE 按 eventId 有序，重连时从 Last-Event-ID 后续传；必要时用 REST 快照校正 | 实时观察 | 3 |
| RO-R9 | 可观测能力只读取结果和事件，不反向修改测试任务、Task、Attempt 或资源 | 全流程 | 2～7 |
| RO-R10 | 主页面不渲染 Workflow 图、节点时间线或报告正文；第一块固定为执行资源与队列，第二块固定为测试任务运行与报告列表 | 打开运行与报告 | 3 |
| RO-R11 | 列表一行只代表一个 Test Job，展示任务概述、当前/最近一次执行状态、进度、Commit、Workflow 版本和执行次数；执行中优先，其余按最近执行时间排序 | 加载任务列表 | 3 |
| RO-R12 | “查看报告”只打开该行任务的执行详情；切换执行或离开详情必须关闭旧 SSE，避免跨任务图、状态和报告叠加 | 查看报告/返回 | 4 |
| RO-R13 | 尚无执行记录的任务保留在列表中，但“查看报告”不可用并明确提示尚未执行 | 加载任务列表 | 3 |
| RO-R14 | `WAITING_DEPLOYMENT` 必须显示为“等待 Jenkins 发布”，不能与资源队列 QUEUED 合并；资源队列只统计 Test Job 归属的有效 Run，不统计无 Test Job 的遗留孤立 Run | 概览与流程图展示 | 3、4 |
| RO-R15 | 资源总览在桌面端固定为一行五项：等待发布 Case、待调度 Case、执行中 Case、脚本执行槽、UI 测试机；主指标按调度阶段聚合，脚本/UI 差异只作副说明，Agent 数量归入容量副说明与资源明细 | 加载资源总览 | 3、7 |
| RO-R16 | QUEUED/RUNNING Test Job 必须提供取消入口并显示收敛进度；内部自动 UUID 不进入面向人的列表摘要 | 运行概览 | 3、4 |
| RO-R17 | 报告 Evidence 必须把截图、Trace、日志和其他 Attempt 附件作为可访问条目展示，并标注来源 Case 与类型 | 查看报告 | 4、6 |
| RO-R18 | 首次加载期间显示骨架或 Loading，只有请求成功且集合确实为空时显示空态 | 加载概览/详情 | 3、4 |

## 4. 异常分支

| 编号 | 异常场景/触发条件 | 系统处理 | 用户或调用方可见结果 | 最终状态 |
| --- | --- | --- | --- | --- |
| RO-E1 | 过期 Attempt 尝试写入结果 | 拒绝成为有效 TestResult，只保留执行审计 | 报告不出现旧结果 | 当前 Attempt 结果保持权威 |
| RO-E2 | Run 尚有未终态 Task | 返回进行中快照和已知结果，不宣称完整报告 | 页面显示 pending 数量 | 报告保持未完成 |
| RO-E3 | SSE 连接中断 | 使用 Last-Event-ID 重连，并通过 REST 快照校正 | 页面显示重连状态 | 恢复到最新权威状态 |
| RO-E4 | 历史样本跨脚本版本或环境 | 排除不可比较样本 | 用户看到实际样本范围 | 不产生跨版本 Flaky 结论 |
| RO-E5 | Metrics 后端不可用 | 保留业务结果与报告，标记指标链路降级 | 报告仍可查询 | 不改变业务终态 |

## 5. 本期包含

> 本期只实现下表明确列出的内容；未列出的能力一律不属于本期，不顺带扩展。

| 编号 | 能力或场景 | 完成边界 |
| --- | --- | --- |
| RO-IN1 | 结果与报告 | TestResult、通过率、P50/P95、失败分类和附件索引 |
| RO-IN2 | 历史与 Flaky | 同版本同环境的最近结果序列、切换次数和波动证据 |
| RO-IN3 | 实时事件 | ExecutionEvent、执行快照、SSE 增量和断线恢复 |
| RO-IN4 | 平台观测 | Claim 排队、Provider/Agent/资源容量、Stream Pending、执行耗时与失败分类的 Prometheus 指标、Grafana 面板和关联日志 |
| RO-IN5 | 运行与报告工作台 | 资源/队列总览、按任务聚合的运行报告列表，以及隔离的执行图与报告二级详情页 |
| RO-IN6 | 操作与证据可见性 | 活动任务取消、执行器等待原因、附件入口、稳定 URL 与加载态 |

## 6. 成功标准

| 编号 | 可验证结果 | 验证方式 | 对应流程/规则 |
| --- | --- | --- | --- |
| RO-S1 | 混合成功、失败、阻断和 Fixture 的报告指标与原始有效结果一致 | 构造固定数据并手工复算通过率和 P95 | RO-R1～R4 |
| RO-S2 | 每个结果、失败分类和附件引用都可追溯到 Task、有效 Attempt 和 objectKey | 从报告逐项反查执行记录 | 流程 1、4 |
| RO-S3 | SSE 断线重连后页面状态与 REST 快照一致，不遗漏最终状态 | 记录 eventId、断网、重连并对比快照 | RO-R7、R8、RO-E3 |
| RO-S4 | Flaky 只在同版本同环境窗口出现通过/失败切换时成立 | 构造稳定、波动、跨版本三组历史 | RO-R5、R6、RO-E4 |
| RO-S5 | 可观测组件故障不会改变测试任务当前结果和报告 | 停止观测依赖后查询报告 | RO-R9、RO-E5 |
| RO-S6 | 主页面先显示资源与队列，再显示一行一个测试任务的运行/报告列表；点击查看报告后只出现所选任务的流程图、节点时间线和报告 | 前端组件测试与浏览器交互验收 | RO-R10～R13 |
| RO-S7 | 活动任务可取消、内部 UUID 隐藏、刷新保持当前模块，报告附件可下载且页面无空态闪烁 | 组件测试与浏览器验收 | RO-R16～R18 |
